# Kinetica Plugins

Плагины для [Kinetica Editor](https://github.com/Kinetica-Labs/kinetica-editor) — редактора робототехники.
Каждая папка с `plugin.py` — один плагин на Python: функция с `@command` становится кнопкой в меню
«Плагины», строкой консоли, операцией API и инструментом MCP для ИИ-агента; `@component` вешается на объект
сцены и работает каждый кадр; `ui.panel(...)` — своя вкладка в окне. Стандартная библиотека Python 3 — и встроенный
набор формул плагина `formula` (ниже, «Чужой код»).

| Плагин | Что делает |
|---|---|
| [formula](formula/plugin.py) | Формулы LaTeX в сцене: над объектом (едет с ним, всегда лицом к зрителю), в мире или титром в кадре. Компонент на фигуре, правится в её карточке; «Выноска» — формула в стороне и линия-выноска к точке детали, как на чертеже (`formula_callout` — агенту). Набирает системный LaTeX (`latex`, `dvisvgm`), а без него — встроенный ziamath: ставить ничего не нужно |
| [textures](textures/plugin.py) | Простой процедурный генератор текстур: дерево, кирпич, плитка, бетон, мрамор, металл — бесшовная картинка с рельефом из нескольких чисел (крупность, вариант, свои цвета) на выделенные фигуры; «Образцы» — по кубу каждого рисунка |
| [depz](depz/plugin.py) | Приборы [depz.ai](https://depz.ai) в редакторе. Пока — плата ориентации BNO086 по USB: «Подключить» находит её сама (или порт `/dev/ttyACM0`, `COM5`), включает ориентацию (игровую или с компасом), ускорение и угловую скорость до 400 Гц; углы, ускорение, угловая скорость и кватернион — живыми графиками во вкладке «Графики» (управление — вкладка «depz» инспектора); `depz_imu_read` отдаёт последние отсчёты с часами платы в мкс. Протокол платы — `depz/bno086.py` |
| [teleop](teleop/plugin.py) | «Пульт»: геймпад как устройство пультов сцены — пока сцена идёт, привязки `gamepad` каждого пульта (`left_stick`, `right_x`, курки, кнопки) читаются с геймпада (Linux, `/dev/input/js*`, оси и кнопки — по карте самого устройства) и уходят в `controller_input`; так же ведётся рука UR5e и машинка. Плата ориентации depz как руль — `teleop_board` (в стабилизатор «Мозга»). `teleop_pad_state` — показания геймпада |
| [terrain](terrain/plugin.py) | «Рельеф» одним вызовом (`terrain_make`): неподвижная сетка холмов (коллайдер из её треугольников), ровная середина, уклоны до 11°; с `track` — полигон для низкой машинки: горка 8°, лежачие полицейские 3 см, лёгкие ящики (пирамида) и мячи. Повторный вызов заменяет свои объекты |
| [motors](motors/plugin.py) | «Моторы»: мотор постоянного тока по его устройству — поле магнита в зазоре, длина и радиус ротора, витки, провод, передача — `K` по силе Лоренца и закону Фарадея, `R` по закону Ома (`motors_make` на сустав); пока сцена идёт, над роботом — заряд батареи и `P = U·I` с числами |
| [brain](brain/plugin.py) | Мозг робота: нейросеть (слои любой ширины, по желанию память на шаг и эхо своей команды) читает датчики тела и задаёт его тяги или привод машины (поворот и скорость; шины, мотор, руль по гироскопу и рефлекс отворота от стенки). Учится отбором на всех ядрах, по желанию сразу на нескольких случайных трассах — счёт по худшей; касание стенки — красная карточка; графики поколений в панели и внизу, 20 лучших каждого поколения едут в окне; сеть видна картинкой в панели. «Поставить лучшего» — и ▶; мозг сохраняется в `.brain.json` и загружается на другое тело. «Пример: гонка» приходит с обученным мозгом; «Пример: балансир» — шест на тележке; без окна: `python3 brain/evolution.py сцена.kscene --tracks 4 --out лучший.brain.json` |
| [showcase](showcase/plugin.py) | Сцена-витрина: «Собрать сцену» — рука UR5e над шахматной доской, маятник у башни из брусков, свет, камера с ключами, формулы; ▶ играет историю — рука крутит ферзя и ставит мат, шар сносит башню. Поверхности и формулы — от `textures` и `formula` |

Плагин остаётся в редакторе и даёт ему новое умение. Пример сцены кодом — ряд кубиков, робот с датчиком — это не
плагин, а скрипт: файл Python, который строит сцену и заканчивается. Скрипты лежат в `examples/scripts`
репозитория редактора и запускаются из «Файл → Выполнить скрипт…».

## Подключить

Клонировать вместе с подмодулями — в них встроенный набор формул: `git clone --recursive …`
(уже склонировали — `git submodule update --init`).


Один раз: в редакторе **Плагины → Добавить папку плагинов…** — и выбрать эту папку (корень репозитория);
из скрипта или агентом — операция `plugin_scan {folder: "/путь/к/kinetica-plugins"}`.
Редактор запомнит её и будет запускать плагины отсюда при каждом старте; сохранили `plugin.py` — плагин
перезапустился (~0,2 с).

Без окна, для скрипта или CI: `KE_PLUGINS=/путь/к/kinetica-plugins kinetica`.

## Написать свой

Руководство «плагин за пять минут» — `docs/plugins.md` в репозитории редактора; контракт — его
`docs/contracts/editor-plugin.md`. Коротко:

```python
from kinetica.plugin import command, field


@command(label="Поднять выделенное", key="Ctrl+Shift+U")
def lift(scene, height: float = field(0.1, unit="м", range=(-1.0, 1.0), label="На сколько")):
    """Поднять выделенные объекты - одна правка, сколько бы их ни было."""
    chosen = scene.editor.selection
    if chosen:
        scene.move(*chosen, by=(0, height, 0))
    return {"moved": len(chosen)}
```

`scene` — объектная модель редактора, та же, что в его консоли: `scene.add(...)`, `scene.objects["Куб 1"]`,
`scene.editor.selection`; для операции, которой в ней нет слова, — `scene.ed.<операция>(...)` (список — `ops_list`).
Другого пути к сцене у плагина нет. Файл запускает сам редактор.

Новый плагин — новая папка с `plugin.py`. Имя папки — имя плагина и приставка его команд (`cubes_row`).

## Чужой код

Плагин `formula` набирает формулы без LaTeX чужими библиотеками на чистом Python — подмодули `formula/third_party/`,
каждый закреплён на своём выпуске, лицензии лежат в них самих:

| Что | Выпуск | Лицензия |
|---|---|---|
| [ziamath](https://codeberg.org/cdelker/ziamath) — LaTeX-математика в контуры SVG | 0.13 | MIT; шрифт STIX Two Math — SIL OFL 1.1 |
| [ziafont](https://codeberg.org/cdelker/ziafont) — чтение шрифтов | 0.11 | MIT; шрифт DejaVu Sans — лицензия Bitstream Vera |
| [latex2mathml](https://github.com/roniemartinez/latex2mathml) — разбор LaTeX | 3.81.1 | MIT |
